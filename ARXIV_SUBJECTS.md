## Decision Tree for Tool Selection

```
START: Research Query
│
├─ Is topic in arXiv subjects above?
│  ├─ YES → Is citation count required?
│  │  ├─ YES → Use Semantic Scholar (arXiv has no citations)
│  │  └─ NO → Use arXiv (better quality for STEM)
│  │
│  └─ NO → Use Semantic Scholar (broader coverage)
│
END: Tool Selected
```

## Examples

### ✅ Use arXiv
- "deep learning neural networks"
- "quantum entanglement"
- "differential geometry manifolds"
- "computational complexity theory"
- "econometric time series"

### ❌ Use Semantic Scholar
- "speed bumps traffic safety" (civil engineering)
- "clinical trial diabetes" (medicine)
- "organizational behavior workplace" (business)
- "urban planning sustainability" (urban studies)
- "environmental impact assessment" (environmental science)

### 🤔 Either/Both (overlap areas)
- "computational biology" (both)
- "financial mathematics" (arXiv q-fin or Semantic Scholar)
- "statistical learning" (both)
- "image processing" (arXiv cs.CV or Semantic Scholar)
- "econometrics" (arXiv econ or Semantic Scholar)
